# Grand Midas Rio Convention Suítes

Site institucional do **Grand Midas Rio Convention Suítes**, hotel na Estrada dos Bandeirantes, 6265, Jacarepaguá, Rio de Janeiro/RJ.

## Tecnologias

- HTML5 + CSS3 + JavaScript puro
- Sem frameworks ou dependências externas (exceto Google Fonts)
- Hospedagem: GitHub Pages

## Estrutura

```
├── index.html
├── RESEARCH.md          # Pesquisa e dados confirmados
├── ASSETS-SOURCES.md    # Fontes de imagens e assets
└── assets/
    ├── css/style.css
    ├── js/main.js
    └── favicon.svg
```

## Nota

Tipos de quartos, comodidades, tarifas e fotos devem ser confirmados com o hotel antes da publicação oficial. Nenhuma tarifa é informada no site.
